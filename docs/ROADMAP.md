# 路线图

## v0.4（现在）

- 群聊式交互：一条消息 = 读上下文 + 回话 + 可选动手
- 模糊需求可接：按最合理理解动手并说明假设，而不是打回
- 项目绑定：`room/project.json`，页面底栏可见
- 立刻响应：nudge 唤醒 + 0.5s 轮询 + "正在思考"指示器
- 分阶段推进：「继续」自动带上一阶段报告、失败项、复核意见
- 守卫：工作区绑定、账本基线、工作区基线、无黑框、意图判定、问句不开工
- 工程化：包结构 `agent_team/`、`pyproject.toml`、`agent-team` 命令、218 项回归测试

## v0.5 下一步

1. **流式输出**：大脑边想边说，先把"我打算这么做…"发出来，再补结论；执行阶段也把 Codex 的进度分句发到群里。
2. **真会话记忆**：把群聊历史做摘要压缩，长项目也不会因为上下文超限而丢线索。
3. **任务队列并行**：多个项目/多条任务排队与并发，页面能看到队列。
4. **成本护栏**：单任务 token 预算 + 超预算暂停并问人；页面上显示本次花费。
5. **页面设置区**：工作区、模型、预算、是否自动开工，都能在界面里改，不用手写 json。

## v0.6 之后

- **可插拔执行者**：不只 Codex，也能接其他 CLI Agent（接口已收敛在 `codex_bridge`）。
- **远程执行**：账本在本机、执行在别的机器，用 HTTP 注册 worker。
- **多人协作**：一个群多个用户，各自派活，权限与审计。
- **跨平台**：Linux/macOS 长期跑通，出 Docker 镜像。

## 不做

- 不做云端托管：默认一切跑在本机，账本和代码不出门。
- 不做自动合并/自动发布：合并和上线永远由人拍板。
- 不做无限自治：预算和验收标准是硬约束，超了就停。
