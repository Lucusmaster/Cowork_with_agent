三步装好

需要 Python 3.10 以上、git，和已经登录的 Codex CLI。

  1. 拿到代码

    git clone https://github.com/Lucusmaster/Cowork_with_agent.git && cd Cowork_with_agent && pip install -e .

  2. 体检，然后启动

    启动后会打印一个带一次性码的链接，用它打开群聊。

    agent-team doctor && agent-team start

  3. 让你电脑上的 Agent 学会用它

    装进 Claude Code、Codex CLI、DSH 的技能目录，它们会在合适的时候自己把活交过来。

    agent-team install-skills

网页只绑 127.0.0.1，每个请求都要带令牌。想挂在公网上，先补 HTTPS 和反向代理。
